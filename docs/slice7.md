
# Course Form

Add a form that allows users to enter a new course.

The form should include fields for:
- Course term (Fall, Winter, Spring)
- Course number
- Course title
- Meeting days and times

Add a button to open the course form.

Users should be able to enter course information and submit the form.

The form should also have a Cancel button.

Use React state to manage the form inputs.

Keep the existing features working:
- Display courses
- Term filters
- Select courses
- Course Plan pop-up
- Time conflict detection
