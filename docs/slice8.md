
# Form Validation

Improve the existing Course Form by validating user input before adding a new course.

The form should check that the course number and title are not empty.

Meeting days and times should follow a valid format, such as MWF 11:00-11:50 or TuTh 14:00-15:20.

If the input is invalid, display a clear error message and prevent the course from being added.

Users should be able to correct their input and submit the form again.

Keep the existing course selection, term filters, Course Plan, and time conflict detection working.
