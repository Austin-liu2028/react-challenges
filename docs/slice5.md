# Schedule Pop-up

Add a "Course Plan" button to the course schedule.

When the user clicks the button, show a pop-up listing the courses they have selected.

For each selected course, display the course number, title, and meeting time.

If no courses are selected, show a message explaining that no courses have been selected and that the user can select courses by clicking course cards.

The pop-up should have a close button.

Clicking outside the pop-up should also close it, but clicking inside the pop-up should not close it.
